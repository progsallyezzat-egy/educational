Module 1

🔢 Binary — The Language of Machines

Computers can't read words like we do. They only understand two states: OFF and ON. We write those as 0 and 1 — that's called binary.

Why only 0 and 1?

Electronic circuits are great at telling apart just two states — like a light switch. Flip it OFF, that's a 0. Flip it ON, that's a 1. Simple, and very reliable!

🧠 Feedback Creates Memory

Gates alone only react to the current input — that's called a combinational circuit. But computers need to remember things! Looping the output back as an input creates feedback — and feedback creates memory.
